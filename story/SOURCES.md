# 《归灯》来源登记

本登记与 story/main.ink 一一对应。网站剧情、互动选择与小说正文均以该 Ink 文件为唯一内容源；本文件解释标签中的来源编号，并标出史料实际支持的范围。故事地点是江苏省连云港市连云区连云街道的连云老街。槐安客栈、人物、客簿和灵异事件均为虚构，不对应街区内任何具体真实建筑，也不暗示任何可考建筑发生过本作事件。

`story/main.ink` 是剧情唯一内容源，直接从 `chapter_01` 开始，含12个站点 knot 与两个结局 knot；不存在额外序章 knot。各站 knot 顶部逐项标记 id、title、sourceIds、regionTime、evidence 和 transposition；正文使用 `# prose` 标签，交互动作使用 Ink choice。`story/sources.json` 是来源条目的结构化登记，编译时会嵌入 `chapters.json`。

正史梗概：2006年暴雨夜，红衣新娘顾秋禾与港口捞起的无名男尸陆守成所在的两队在石巷相遇；雨水冲淡客簿上两人的姓名。八岁的沈归落水，沈映禾救他上岸后被潮水带走。她在虚构客簿上留下自己的姓名，并写下“带沈归归家”的去向；雨痕与梁叔的誊抄把残存的“沈｜归家”误合为“沈归”。笔仙游戏让童年的沈归看见错读，不是错名产生的史实解释。2026年沈归回到连云老街，查清母亲留下的归家记录，并决定点灯送母亲离开，或在母亲离开后接灯守巷。所有人物、客簿机制、超自然因果和结局均为虚构创作。

运行 `node story/compile.mjs` 会用 InkJS 编译并确定性生成 `public/story/story.json`、`public/story/chapters.json` 与 `novel/归灯.md`。入巷内容并入 `chapter_01`，章节索引中的 `startKnot` 为 `chapter_01`；`chapter_12` 中的两个 Ink choices 设置结局 flags 并分别进入 `ending_release`（归灯）或 `ending_called`（界面标题为“留灯守巷”）。`ending_called` 是既有 Ink knot ID，不表示沈归延续错名或把母亲留在客簿。来源登记与 Ink 各站 `sourceIds` 一一对应。

## 线索链说明

故事的单一因果链是：2006年暴雨夜，红衣新娘顾秋禾与白队从港口捞起的无名男尸在石巷相遇；后来衣物线索确认死者姓名为陆守成。客簿上两条姓名记录被雨水洗淡。八岁的沈归落水，沈映禾救他上岸后被潮水带走；她在客簿上以自己的姓名留下记录，并写明“带沈归归家”的去向。雨水模糊了“沈映禾”和“带幼子”等字，梁叔将残存的“沈｜归家”誊成一个姓名“沈归”。幼年笔仙段落呈现沈归如何看到这道错读，但笔仙不是账簿出错或亡者异变的历史解释。尸体因错误记录回应、红白影像反复出现、黑白无常依簿核名，均是本作的超自然规则。2026年沈归回到老街，查明母亲替他留下的归家去向；他把顾秋禾、陆守成、沈映禾三人的名字写回后，可送母亲离开，或在母亲离开后接灯守巷。

“客簿拘魂”“笔仙造成尸变”“黑白无常受客簿调度”都是本作原创超自然规则。原典和研究仅分别支撑文学母题、现代游戏研究、信仰形象和现实街区背景；它们不构成这段故事的史实证明。
