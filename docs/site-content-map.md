# 《归灯》连云老街夜行故事：网站内容地图与剧情脚本

## 项目定位

把《归灯》做成一段由十二个独立画面组成的互动故事。故事发生于真实的连云老街，读者跟着成年后的沈归重走2006年的记忆，通过旧物、街坊、原典和现代媒介片段拼出客簿错名的因果。章节以按钮和街区地图切换，不依赖滚轮推进。知识内容不是旁白百科，而是每站可主动打开的“异闻札记”：先读剧情摘要，再按兴趣分页展开来源、地域、媒介案例与创作转译。

连云老街是真实故事地点，石街、石墙、传统街巷和院落形态来自官方街区资料；叙事中的祖宅、纸扎铺、旧戏台、影院、游戏铺和槐安旅社均为虚构场所，不对应街区内具体真实建筑。沈归、街坊、客簿和灵异事件也均为创作内容，不声称发生过真实案件或地方传说。参考现实空间只为建立方向感，不把可考建筑写成本作案发地。

## 故事主线

2026年七月十四的雨夜，成年后的沈归在连云老街收到母亲沈映禾留下的信：“把客簿里挤成一个人的字拆开。听见有人叫你回家，先看灯下有没有影子。”十二站逐渐拼出2006年的旧案：红衣新娘顾秋禾追着滚落的红灯走向港边，此后没有回来；白队抬着从港口捞起的无名男尸陆守成，与红队在石巷相遇；八岁的沈归落水，母亲救他上岸后失踪。母亲曾以自己的名字替儿子在夜簿留下归家一栏，梁叔却把“沈映禾”和“带沈归归家”误抄成“沈归”。黑白无常按簿核名是本作的虚构规则。

每一站都交给玩家一项具体动作和一片线索。旧夜簿的两行死者姓名被暴雨洗空，母亲用自己的姓名替幼子登记归家去向却被抄错。尾声玩家把顾秋禾、陆守成、沈映禾三人的姓名归位后，可送母亲离开，也可接过黄铜灯成为下一任守灯人。

## 交互与节奏约定

- 每站都是独立单屏界面，滚轮不承担章节切换。桌面用章节轨道和上一站/下一站跳转；村落总览显示十二个可点击位置，地图可拖动、缩放并复位。手机端将站点显示为整屏清单，避免地图标记拥挤。
- 主画面展示剧情摘要和明确的探索动作；“阅读本章全文”以逐段分页补足完整剧情。研究内容也逐条分页，弹层不依赖滚动，提供详细解释、地域限定、来源链接和“这如何进入《归灯》”说明。
- 收集到的线索进入“归客手记”。手记按故事线索与异闻札记分页；资料卡可以独立查看，不要求玩家解完谜题才能读。
- 环境声默认关闭，用户主动开启；提供可键盘访问的声音开关。动效响应 `prefers-reduced-motion`，不以动效承担唯一信息。
- 每个研究卡片使用 **史料概述 / 地方实践 / 作品分析 / 创作转译** 标签。引用显示机构或作者、资料名与外链；资料只支持某一地区时，在标题旁直接显示地区。
- 页面本身不产生纵向溢出：章节、手记、来源、全文和札记都在限定视口中切换或分页。键盘用户可使用章节链接、地图方向键、交互控件和显眼焦点状态完成路线。

## 文案语气与内容密度

剧情使用短句、物件细节和可疑的记忆互相拉扯，不用连续跳吓替代情节。知识卡片以日常读者能读懂的说明开始，再逐层展开背景和限制。每站至少回答一个明确问题，例如“这一段属于什么类型的资料”“是谁在什么地方做这件事”“这件道具在作品里被改造成什么”。

本作不会为满足“内容丰富”而编造历史人物、真实仪式或虚构引文。需要填补剧情空白时，填入原创人物与虚构事件，并明确标记为作品设定。
