## 谜题一 · 问卦「困」——第 5 站「石街：红衣与白衣同行」

**用到的真实规则（出处）**
- 三钱代蓍：南宋朱熹《朱子语类》"今人以三钱当揲蓍"；文王卦源流汉代《京氏易传》→宋代《火珠林》确立；唐代以钱占卜见《太平广记》。（文献，转引自维基"文王卦""火珠林"条，正式引用前对校纸本）
- 困卦卦辞「困：亨，贞大人吉，无咎，有言不信」＋九五爻辞「劓刖，困于赤绂，乃徐有说，利用祭祀」。（文献，维基文库十三经注疏本）
- 真实揲蓍是十八变三爻成卦；游戏内简化为"掷三枚铜钱六次成卦"，民俗志条目必须说明此为简化。

**谜题流程**
1. 玩家在石街灵棚的祭案前，点击铜钱开始问卦：掷三枚铜钱六次，每次记一爻
   （3 字＝老阳、3 背＝老阴、2 字 1 背＝少阳、1 字 2 背＝少阴；动爻在本谜题中不展开）。
2. 本次问卦结果固定为**困卦**（剧情注定，文档与 UI 均声明"这一卦是注定的"，不伪装成随机天意）。
3. 卦辞面板展示九五爻辞"**利用祭祀**"四字（附民俗志链接"困卦：'利用祭祀'是什么意思"）。
4. 玩家调查祭案，发现香、烛、纸钱齐备，**缺酒**——"利用祭祀"即线索：祭品还没备齐。
5. 玩家在第 5 站场景中找到"一壶酒"（可拾取物品），对祭案使用。

**答案判定逻辑**
- 通过条件：`使用的物品 === 缺失祭品（酒）`。放错物品 → 梁叔台词注脚"有言不信"（困卦卦辞"有言不信"的呼应，纯氛围）。
- 问卦动画本身不设失败分支（流程教学性质）。

**玩家操作**：点击铜钱 ×6 → 阅读卦辞 → 调查祭案 → 拾取酒壶 → 对祭案使用。
**涉及虚构人物**：送行队伍（虚构）、梁叔（虚构，台词注脚）。
**虚实边界声明（必须进 UI 文案）**：起卦流程与卦辞爻辞原文是真实的；"掷出此卦＝亡魂在求祭品""这一卦注定出现"是游戏虚构；**不断吉凶**（不出现"大吉/大凶"字样）。

## 谜题二 · 沈映禾"残缺命书"——第 4 站「祖宅：红嫁衣与母亲的照片」

**用到的真实规则（出处）**
- 五鼠遁歌诀："甲己还加甲，乙庚丙作初，丙辛从戊起，丁壬庚子居，戊癸何方发，壬子是真途。"（**文献**，2026-10-02已对校《三命通會》卷二《論遁月時》维基文库本；异文"直途/真途"）
- 时辰地支对照：子 23–1、丑 1–3、寅 3–5、卯 5–7、辰 7–9、巳 9–11、午 11–13、未 13–15、申 15–17、酉 17–19、戌 19–21、亥 21–23。（子平术通行规则）
- 地支—生肖对应：子鼠、丑牛、寅虎、卯兔、辰龙、巳蛇、午马、未羊、申猴、酉鸡、戌狗、亥猪。（常识）
- 书目出处：《渊海子平》（宋徐大升→明杨淙）、《三命通会》（明万民英，入四库全书）。（文献，书目级）

**谜题流程**
1. 玩家在祖宅调查梁叔遗物，发现一张被撕去一角的"命书"：年柱、月柱、日柱可读，时柱被撕掉；旁注小字"**时上起，遁得之**"。同一抽屉里有一把三位生肖转盘锁。
2. 旧信／户籍卡给出沈映禾的出生时辰（如"生于戌时"）——剧情内直接给出的真实信息。
3. 玩家查阅民俗志《五鼠遁：没有钟表的时代怎么定"时柱"》（纯流程知识条目）。
4. 推演（真实规则）：以日柱天干对照五鼠遁歌诀定子时天干 → 从子时按地支序顺数到出生时辰 → 得时柱干支 → 取**时柱地支**。
5. 时柱地支对应生肖；生肖转盘按"**时支生肖 → 出生时辰地支 → 日支生肖**"顺序拨动，开锁，取得线索（母亲留下的去向记录）。

**规则演示示例（非剧情定稿，数值待 Phase 2.3 定稿）**：若日干为"甲"，按"甲己还加甲"得子时为甲子；顺数至戌时得时柱"甲戌"；时支戌＝狗。

**答案判定逻辑**
- 通过条件：`转盘三位 === [时支生肖， 出生时辰地支， 日支生肖]`。拨错 → 锁无反应，可重试（无惩罚）。
- 命书残页上原有的断语一律**涂黑／撕掉展示**，UI 与文档均声明"本作不呈现、不认可任何命理断言"。

**玩家操作**：阅读残页 → 查民俗志歌诀 → 拨动三位生肖转盘。
**涉及虚构人物**：沈映禾（虚构）、梁叔（虚构，锁的制作者）。
**虚实边界声明（必须进 UI 文案）**：五鼠遁、时辰对照是真实的子平术规则（**文献**，2026-10-02已对校《三命通會》卷二《論遁月時》）；"排出的时柱能打开这把锁"是游戏虚构（锁是梁叔按此规则定制的机关）；**绝不出现"此命如何如何"的断语**。

## 谜题三 · 七魄灯——第 12 站「黎明双结局：归灯或留灯」

**用到的真实规则（出处）**
- 七魄名目：《云笈七签》收录摄魂还魄法——"呼七魄名曰：尸苟、伏矢、雀阴、吞贼、非毒、除秽、臭肺"（PDF 原文已核实；"尸苟"为"尸狗"异文）。（文献）
- 抱朴子《内篇》葛洪："人无贤愚，皆知己身之有魂魄，魂魄分去则人病，尽去则人死。故分去则术家有拘录之法，尽去则礼典有招呼之义……"（PDF 原文已核实）。（文献，仅作文化注脚）
- 与 S13"名即其身"互补："魂魄有名可摄"——呼名可摄的"理"，与"喊魂/招魂"之"礼"互证。

**谜题流程**
1. 点灯结局前，沈归面前有七盏未点亮的灯（每盏对应一位"影子"的去向牌位，牌上名姓模糊）。
2. 玩家查阅民俗志《三魂七魄：古人身体里的"住户名单"》，得七魄名目与顺序。
3. 按 **尸狗 → 伏矢 → 雀阴 → 吞贼 → 非毒 → 除秽 → 臭肺** 的顺序依次点亮七盏灯。

**答案判定逻辑**
- 通过条件：`点亮顺序 === 七魄名目顺序`。点错 → 灯熄灭，可重来（无惩罚）。
- 只用"七个名字 → 七盏灯"的**计数对应**；"念出名字就能定住魂魄"不用作生效机制。

**玩家操作**：依次点击七盏灯。
**涉及虚构人物**：沈映禾（点灯送母）、两列影子（虚构）。
**虚实边界声明（必须进 UI 文案）**：七魄名目与顺序是文献；"按此顺序点灯即安魂"是游戏虚构，只作用于虚构人物；"爽灵/夹灵"异文待版本对校，本谜题不用。
